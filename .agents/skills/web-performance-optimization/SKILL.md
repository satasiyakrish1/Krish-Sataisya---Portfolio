# Web Performance

1. Measure or identify the actual bottleneck first.
2. Optimize React rendering and component structure.
3. Reduce unnecessary network requests and bundle size.
4. Optimize images, assets and lazy loading.
5. Improve API response times and database queries.
6. Use caching where appropriate.
7. Avoid premature optimization.
8. Verify improvements without breaking functionality.
