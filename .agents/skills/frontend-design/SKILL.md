# Frontend Design

1. Inspect the existing design system before coding.
2. Maintain consistent typography, colors, spacing and components.
3. Prioritize visual hierarchy and usability.
4. Build responsive layouts for mobile, tablet and desktop.
5. Use semantic HTML and accessible interactions.
6. Include loading, empty, error and success states.
7. Avoid generic layouts and unnecessary visual effects.
8. Reuse existing components and dependencies.
9. Verify the interface in the browser when possible.
