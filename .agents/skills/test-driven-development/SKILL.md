# Test-Driven Development

1. Understand expected behavior and acceptance criteria.
2. Inspect existing tests and testing framework.
3. Write a focused failing test where practical.
4. Implement the smallest solution.
5. Run relevant tests.
6. Fix regressions before completing the task.
7. Add edge-case coverage for important behavior.
8. Never claim tests passed without running them.
