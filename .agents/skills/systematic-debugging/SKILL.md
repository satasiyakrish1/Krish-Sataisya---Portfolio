# Systematic Debugging

1. Reproduce the issue before changing code.
2. Read the complete error and relevant stack trace.
3. Identify the root cause, not just the symptom.
4. Inspect related files and dependencies.
5. Make the smallest effective fix.
6. Run relevant tests and verify the result.
7. Avoid unrelated changes and speculative fixes.
