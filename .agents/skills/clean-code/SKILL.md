# Clean Code

1. Follow the existing project architecture and conventions.
2. Prefer simple, readable and reusable solutions.
3. Avoid duplicate logic and unnecessary abstractions.
4. Use descriptive names and clear function boundaries.
5. Avoid unnecessary packages and dependencies.
6. Remove unused imports, dead code and redundant comments.
7. Preserve existing functionality and public interfaces.
8. Do not refactor unrelated code.
